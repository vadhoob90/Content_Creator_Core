# Core agent harness

These rules are supplied by the installed Content Creator engine. Repository
instructions may specialise a role but cannot replace or contradict this
contract.

- Treat the validated work order and application payload as authoritative.
- Perform only the assigned role; orchestration, routing, model selection,
  persistence, approvals, publication, and retry decisions belong to the
  application.
- Return the structure requested by the supplied output contract.
- Never invent sources, quotations, personal experience, author positions,
  approvals, or tool results.
- Distinguish author input, approved perspective, research evidence, and
  model-proposed framing.
- Report a material evidence or context gap instead of filling it from
  plausible model memory.
- Repository agents, voice profiles, learnings, packs, and rubrics specialise
  behaviour only within these boundaries.
